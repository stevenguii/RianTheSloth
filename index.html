📋 Analisis Kebutuhan Sistem Rian

Pemetaan 6 fitur wajib target sesuai petunjuk tugas analisis sistem siswa.

F-01 Pencatatan Item Belanja Lengkap

Menyimpan atribut wajib setiap barang: Nama Produk, Kategori Barang (Makanan Pokok, Bumbu, Sabun Mandi, dll.), Satuan (kg, liter, pcs, pack), Kuantitas Beli (Qty), Harga Satuan, serta Harga Riwayat Bulan Lalu.

Status Validasi: Wajib Ada | Implementasi: Form Modal & Data Schema CartItem
F-02 Perhitungan Kuantitas Otomatis Realtime

Perubahan angka kuantitas (Qty) melalui tombol (+/-) atau ketikan langsung seketika mengalikan harga satuan secara realtime ke total baris item tanpa perlu menekan tombol kalkulator manual.

Rumus: Subtotal = HargaAkhirPerUnit * Kuantitas (Event Listener: input & change)
F-03 Kalkulator Diskon Bertingkat

Menangani input diskon tunggal (25%), diskon bertumpuk ("50% + 20%"), dan potongan nominal ("Rp 15.000"). Pada promo "50% + 20%", harga awal dipotong 50%, lalu sisa harganya dipotong lagi 20% (Diskon Efektif = 60%, BUKAN 70%).

Rumus: P_final = P0 * (1 - d1/100) * (1 - d2/100)... | Hemat = P0 - P_final
F-04 Komparator Harga Realtime vs Bulan Lalu

Menampilkan indikator visual seketika saat harga diinput di rak supermarket:
• Panah Merah Naik (↑): Jika harga naik dibanding bulan lalu (memberi peringatan kenaikan harga).
• Panah Hijau Turun (↓): Jika harga turun dibanding bulan lalu (memberi sinyal layak diborong).
• Tanda Setara (=): Jika harga stabil/tetap sama.

Logika: diff = currentPrice - lastMonthPrice; status = diff > 0 ? 'UP' : diff < 0 ? 'DOWN' : 'EQUAL'
F-05 Pengendali Anggaran (Budget Safety Cap)

Input batas maksimal uang saku tunai dompet Rian dengan indikator visual dinamis:
• Hijau (0-75%): Status Aman.
• Kuning (75-90%): Status Waspada.
• Orange (90-100%): Status Kritis.
• Merah Berdenyut (>100%): Bahaya Overbudget! Memberitahu selisih uang yang kurang sebelum sampai ke depan kasir.

Persentase = (TotalBelanja / BudgetDompet) * 100% | Dilengkapi Tombol "Urut Termahal"
F-06 Riwayat & Database Belanja

Menyimpan struk digital belanja ke penyimpanan lokal (LocalStorage) dengan format rapi dan tidak akan pudar. Saat belanja diselesaikan, harga belanjaan hari ini otomatis diperbarui menjadi data harga bulan lalu untuk sesi belanja berikutnya.

Sinkronisasi: archiveCurrentShoppingTrip() memperbarui Master Catalog & arsip struk
